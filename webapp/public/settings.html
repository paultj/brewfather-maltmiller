Welcome

To get started, add your own Anthropic API key (this pays for Claude, usually a few pence per recipe) and your Brewfather API key (so recipes go into your Brewfather account and Claude can see your inventory). Then press Save and go back to recipes.

Claude

Your own key, from console.anthropic.com → API keys. It's stored encrypted and never shown again. We suggest setting a monthly spend limit on it in the Anthropic Console (Settings → Limits). Leave blank to keep the saved key.

Brewfather

In Brewfather: Settings → API → Generate API key. Tick Read Inventory and Edit Recipes (recipes.write). Leave blank to keep the saved key.
The Brewfather API can't read equipment profiles directly, so the app copies them from one of your recipes: the equipment (boil-off, losses, efficiency, batch volume type) and the water setup (your source water report; the target profile too when the new recipe is the same style). Pick a recipe that uses your usual equipment and water. Salt amounts are left for Brewfather's water calculator.
